## ۱. خلاصه اجرایی

### ۱.۱ بیانیه مسئله

بازار آموزش آنلاین ایران با **۱۵ میلیون دانش‌آموز**، **۱.۲ میلیون معلم** و **۱۰,۰۰۰+ آموزشگاه** فاقد یک پلتفرم آزمون‌ساز بومی حرفه‌ای است که:

- رابط کاربری کاملاً فارسی و RTL داشته باشد
- با هوش مصنوعی بومی سوال تولید کند
- درگاه پرداخت ریالی داشته باشد
- با زیرساخت ایران سازگار باشد
- با آخرین استانداردهای جهانی ۲۰۲۶ رقابت کند

### ۱.۲ راه‌حل

ساخت پلتفرم **آزمون‌ساز آنلاین فارسی** با نام کاری **«آزمونیار»** — یک SaaS کامل که ترکیبی از بهترین ویژگی‌های Jotform، Kahoot، Typeform و FlexiQuiz را با بومی‌سازی کامل برای بازار ایران ارائه می‌دهد.

### ۱.۳ مزیت رقابتی اصلی

| مزیت | توضیح |
|------|-------|
| 🤖 AI مکالمه‌ای فارسی | ساخت آزمون کامل از طریق گفتگو با AI |
| 🎮 گیمیفیکیشن پیشرفته | Confidence Mode، Live Quiz، لیدربورد |
| 🔒 امنیت بومی | Proctoring بدون نرم‌افزار جانبی |
| 💳 پرداخت ریالی | زرین‌پال، IDPay، پرداخت مستقیم |
| 📱 موبایل‌فرست | طراحی اول برای موبایل ایرانی |
| 🏆 گواهینامه بلاکچین | تأیید اعتبار جهانی |

### ۱.۴ خلاصه مالی

| معیار | مقدار |
|-------|-------|
| سرمایه‌گذاری مورد نیاز | ۵ میلیارد تومان |
| بازگشت سرمایه (ROI) | ۱۸ ماه |
| MRR هدف (ماه ۱۸) | ۵۰۰ میلیون تومان |
| ARR هدف (سال ۲) | ۶ میلیارد تومان |
| کاربر هدف (ماه ۱۸) | ۱۰۰,۰۰۰ کاربر فعال |

### ۲.۲ روندهای بازار ۲۰۲۶

- **رشد EdTech ایران:** ۳۵٪ رشد سالانه پس از کرونا
- **تقاضای AI:** ۷۸٪ معلمان ایرانی خواهان ابزار AI هستند
- **موبایل‌محوری:** ۸۵٪ دانش‌آموزان از موبایل استفاده می‌کنند
- **گیمیفیکیشن:** ۶۷٪ افزایش تعامل با محتوای گیمیفای‌شده
- **بازار گواهینامه دیجیتال:** رشد ۲۱.۷٪ سالانه جهانی

### ۳.۴ مزیت رقابتی پایدار

**چرا رقبا نمی‌توانند کپی کنند؟**

1. **پرس‌لاین:** برای اضافه کردن AI مکالمه‌ای و گیمیفیکیشن نیاز به بازنویسی کامل دارد
2. **Jotform/Typeform:** برای ورود به بازار ایران نیاز به سرمایه‌گذاری بومی‌سازی دارند
3. **Kahoot:** تمرکز روی آموزش زنده، نه آزمون رسمی
4. **ما:** از ابتدا برای بازار ایران + استانداردهای ۲۰۲۶ طراحی شده‌ایم

## ۴. راه‌حل پیشنهادی

### ۴.۱ معرفی محصول

**آزمونیار** یک پلتفرم SaaS آزمون‌ساز آنلاین فارسی است که در سه لایه ارائه می‌شود:

```
┌─────────────────────────────────────────────────────────────┐
│                    لایه ۱: ابزار ساخت                       │
│   AI مکالمه‌ای │ ویرایشگر بصری │ بانک سوال │ قالب‌ها        │
├─────────────────────────────────────────────────────────────┤
│                    لایه ۲: برگزاری                          │
│   آزمون زنده │ آزمون آنلاین │ خودآزمایی │ آزمون تطبیقی     │
├─────────────────────────────────────────────────────────────┤
│                    لایه ۳: تحلیل و یادگیری                  │
│   گزارش‌دهی │ Spaced Repetition │ Agentic AI │ گواهینامه    │
└─────────────────────────────────────────────────────────────┘
```

### ۴.۲ جریان اصلی کاربر (User Flow)

**جریان مدرس:**
```
ثبت‌نام (۳۰ ثانیه)
    ↓
گفتگو با AI: «یه آزمون ۲۰ سوالی از فصل ۳ شیمی بساز»
    ↓ (۶۰ ثانیه)
آزمون آماده — ویرایش دلخواه
    ↓
انتشار — لینک/QR/پیامک
    ↓
برگزاری — مشاهده زنده
    ↓
گزارش خودکار — نمرات + تحلیل
    ↓
گواهینامه خودکار برای قبول‌شدگان
```

**جریان دانش‌آموز:**
```
دریافت لینک
    ↓
ورود (بدون ثبت‌نام اجباری)
    ↓
شرکت در آزمون
    ↓
نتیجه فوری + بازخورد
    ↓
گواهینامه (در صورت قبولی)
    ↓
پیشنهاد مطالعه بیشتر (Spaced Repetition)
```

### ۴.۳ ویژگی‌های تمایزدهنده

#### ۱. AI مکالمه‌ای فارسی (Chat-to-Quiz)
اولین پلتفرم ایرانی که آزمون را از طریق **گفتگوی فارسی** می‌سازد:
- «یه آزمون ۱۵ سوالی درباره انقلاب مشروطه بساز»
- «سوال ۵ رو سخت‌تر کن»
- «تایمر رو ۴۵ دقیقه کن و نمره منفی اضافه کن»

#### ۲. Confidence Mode
دانش‌آموز علاوه بر پاسخ، سطح اطمینان خود را اعلام می‌کند — ابزار اندازه‌گیری **metacognition** که در ایران بی‌سابقه است.

#### ۳. Spaced Repetition بومی
الگوریتم تکرار فاصله‌دار با پشتیبانی از محتوای فارسی — ۲۰–۴۰٪ بهبود نگهداری دانش.

#### ۴. گواهینامه بلاکچین
اولین گواهینامه دیجیتال ایرانی با استاندارد W3C Verifiable Credentials — قابل تأیید توسط کارفرماها.
