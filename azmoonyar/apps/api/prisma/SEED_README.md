# راهنمای Seed Data

این فایل شامل داده‌های نمونه برای محیط توسعه است که به شما کمک می‌کند سریع‌تر شروع به کار کنید.

## 🌱 نحوه اجرای Seed

```bash
# اجرای seed
npm run db:seed

# بررسی داده‌های seed شده
npm run db:verify

# ریست کامل دیتابیس و اجرای مجدد seed
npm run db:reset
```

## 📝 نکات مهم

1. **همه شماره موبایل‌ها فرضی هستند** و برای محیط توسعه استفاده می‌شوند
2. برای ورود با OTP، سیستم باید سرویس پیامک متصل باشد یا در حالت Development کد OTP ثابت باشد
3. داده‌های seed شامل **تنوع کامل انواع سوالات** است برای تست همه ویژگی‌ها
4. برخی آزمون‌ها دارای **submission های تکمیل شده** هستند برای تست گزارشات
5. گواهینامه‌ها با **کد یکتا** صادر شده‌اند و قابل تایید هستند

## 🧹 پاک کردن داده‌ها

```bash
# ریست کامل و اجرای مجدد migrations + seed
npm run db:reset

# فقط پاک کردن دیتابیس (بدون seed)
npx prisma migrate reset --skip-seed
```

## 🔍 بررسی داده‌ها

```bash
# مشاهده داده‌ها با Prisma Studio (UI)
npm run db:studio

# بررسی با اسکریپت verify
npm run db:verify

# اتصال مستقیم به دیتابیس
psql postgresql://azmoonyar:password@localhost:5432/azmoonyar_dev
```

## 🚀 استفاده در تست‌ها

می‌توانید از این داده‌های seed شده در تست‌های integration استفاده کنید:

```typescript
import { PrismaClient } from '@prisma/client';

const prisma = new PrismaClient();

// دریافت استاد نمونه
const teacher = await prisma.user.findUnique({
  where: { phone: '09133333333' }
});

// دریافت آزمون نمونه
const exam = await prisma.exam.findFirst({
  where: { status: 'PUBLISHED' }
});
```
